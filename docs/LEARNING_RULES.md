# Learning and Review Rules

## Lesson cycle

1. Study the lesson slowly.
2. Ask questions whenever a word or idea is unclear.
3. Complete the exercise without copying.
4. Commit answers to the chapter answer file.
5. Request a review.
6. Correct technical misunderstandings and English mistakes.
7. Mark the chapter completed.
8. Unlock the next chapter.

## Teaching style

- Absolute-beginner explanations first
- One concept at a time
- Simple English before professional terminology
- Practical examples from Java, Spring Boot, PostgreSQL, SAP BTP and cloud systems
- Safe exercises with no unauthorized targets
- Regular revision and small knowledge checks

## English improvement

Each review will separate:

- **Technical correction:** What the security concept should mean
- **Grammar correction:** How to write the sentence correctly
- **Vocabulary improvement:** A clearer professional word or phrase

Mistakes are part of learning. Write answers yourself, even when the sentences are short.

## Evidence of learning

Each completed module should produce at least one artifact:

- Written answers
- Diagram
- Configuration
- Small program
- Threat model
- Risk register
- Security report
- Incident timeline

These artifacts will form a cybersecurity portfolio.
