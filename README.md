# Cybersecurity Learning Journey

A structured, practical journey from absolute beginner to job-ready cybersecurity practitioner.

## Student

**Danesh Naik**

## Learning method

Every chapter contains:

1. A simple explanation
2. Important technical terms
3. Real-world examples
4. A safe practical lab
5. Exercises and an answer template
6. Common mistakes
7. A short knowledge check
8. English vocabulary and sentence practice
9. Progress updates after review

> Complete one chapter at a time. Submit your answers before moving to the next chapter.

## Start here

1. Read [Ethics and Safety](docs/ETHICS_AND_SAFETY.md).
2. Read the [Learning Roadmap](ROADMAP.md).
3. Prepare only the tools required by the current lesson using [Lab Setup](lab/README.md).
4. Study [Chapter 01: What Is Cybersecurity?](chapters/01-cybersecurity-foundations/lesson.md).
5. Complete the [Chapter 01 Exercise](chapters/01-cybersecurity-foundations/exercise.md).
6. Write your answers in the [Answer Template](chapters/01-cybersecurity-foundations/answers.md).
7. Update [Progress](PROGRESS.md) after the answers are reviewed.

## Main tracks

- Computer, Linux and networking fundamentals
- Security foundations and risk management
- Web, API and Java application security
- Identity, cryptography and database security
- Cloud, containers, SAP and DevSecOps security
- Defensive security, incident response and SOC
- Ethical penetration testing in authorized labs
- Professional portfolio and interview preparation

## Important rule

Use cybersecurity knowledge only on systems you own or have explicit written permission to test.
